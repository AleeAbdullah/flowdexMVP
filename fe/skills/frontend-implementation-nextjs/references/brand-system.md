## Brand Pillars

### Universal Access

- One platform for every asset class
- No broker accounts
- No geographic restrictions
- No market-hours framing

### Non-Custodial Trust

- Assets never leave the user's wallet
- Trades settle on-chain
- Transparency is a core trust signal
- Mentioned audit references in the PDF: Trail of Bits, OpenZeppelin, Zellic

### Institutional Precision

- Aim for a Bloomberg Terminal-like aesthetic
- Keep interfaces data-dense and deliberate
- Make every visual choice feel purposeful and finance-grade

### Community Ownership

- 75% community-owned
- No VC positioning
- 40% of protocol fees flow to `$FDN` stakers
- Quadratic DAO governance

## Personality And Voice

- Professional but not corporate
- Technical but accessible
- Confident but not aggressive
- Sound like a senior DeFi engineer who also understands equities and forex
- Explain complex multi-asset concepts with clarity and precision

## Logo Rules

### Structure

- Diamond-shaped mark with a stylized `F`
- Wordmark: `FlowDex`
- The diamond stands for convergence of multiple asset classes

### Variants

- Primary: cyan mark with white wordmark on dark background
- Reversed: white mark with dark wordmark on light background
- Monochrome: one-color constrained use
- Mark only: favicon and small-icon contexts, 32px and above
- Wordmark only: inline layouts
- Tagline version: `FlowDex - The Universal Exchange`

### Spacing

- Minimum clear space equals the height of the `F` inside the mark
- Minimum digital width: `120px`
- Minimum print width: `30mm`
- Tagline logo minimum width: `200px`

## Typography

### Primary Typeface

- Font: `Outfit`
- Use for headings, body, buttons, labels, tabs, and descriptions
- Use for every non-numeric interface string

### Mono Typeface

- Font: `JetBrains Mono`
- Use only for financial data:
  - token prices
  - stock prices
  - forex rates
  - commodity values
  - wallet addresses
  - amounts
  - percentages
  - portfolio values

### Type Scale

- Desktop:
  - Hero: `72px`
  - H2: `40-44px`
  - H3: `22px`
  - Body: `15px`
  - Small: `12px`
  - Micro: `10px`
- Mobile:
  - Hero: `38px`
  - H2: `28px`
  - H3: `18px`
  - Body: `14px`
  - Small: `11px`
  - Micro: `9px`

### Weight Guidance

- `900`: hero headlines
- `800`: section headings
- `700`: card titles, CTAs, asset names
- `600`: nav, labels, asset category tabs
- `400`: body text, descriptions
- `300`: captions, disclaimers, legal

## Component Rules

### Buttons

- Primary: cyan background, navy text, `12px` radius
- Primary hover: `brightness(1.1)`
- Secondary: glass background, white text, `1px` border
- Secondary hover: border shifts toward cyan
- Active press: `scale(0.97)`

### Asset Category Tabs

- Each asset class uses its dedicated accent color
- Active tab: colored border, `12%` tinted fill, accent-colored text
- Inactive tab: transparent background, muted text, subtle border
- Format: icon plus label

### Cards, Badges, Inputs

- Cards use glass backgrounds, blur, `1px` border, `16px` radius
- Live badge: pill shape, green pulse dot, cyan text, accent border/background
- Trust badges: `11px`, muted text, green-check prefix
- Price displays: `JetBrains Mono` plus green/red deltas
- Inputs: `rgba(5,12,22,.6)` background, `10-12px` radius
- Tokenized asset attribution: inline cyan provider tag such as `via Ondo` or `via Backed`

## Copy Do And Don't

### Do

- Use exact hex values
- Use `JetBrains Mono` for all financial data
- Use `Outfit` for all non-data text
- Keep the cyan accent as the primary action color
- Maintain glassmorphism on all cards
- Show RWA provider attribution when relevant
- Test both dark and light mode
- Use `Universal Exchange` in marketing
- Make `Non-custodial` highly visible

### Do Not

- Do not call FlowDex a `DEX aggregator`
- Do not use Inter, Roboto, Arial, or system fonts
- Do not use purple gradients or generic AI aesthetics
- Do not place the logo on busy backgrounds without clear space
- Do not flatten cards and remove the blur effect
- Do not show stock or forex prices in `Outfit`
- Do not omit asset type labels in portfolio views
- Do not imply custody with words like `deposit`, `withdraw`, or `account balance`
- Do not break the 768px and 1024px responsive checkpoints
- Do not use `invest` language when `trade`, `swap`, or `participate` is more accurate
